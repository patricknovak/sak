# Fonts for the link-preview pictures

Barlow Condensed (Jeremy Tribby) and Inter (Rasmus Andersson), static instances from Google Fonts, both under the SIL
Open Font License 1.1 (https://openfontlicense.org). The same faces the site and the landing page use, as TTF because
the picture renderer (satori) reads TTF, not WOFF2.
